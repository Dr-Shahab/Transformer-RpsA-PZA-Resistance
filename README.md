# Transformer-RpsA-PZA-Resistance
This repository contains the data processing scripts, Transformer-based deep learning models, virtual screening pipeline, molecular docking protocols, and molecular dynamics simulation workflows used to identify inhibitors targeting the RpsA Δ438 deletion associated with pyrazinamide resistance in Mycobacterium tuberculosis.
